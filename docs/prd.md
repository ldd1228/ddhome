# 温暖亲切个人展示网站需求文档

## 1. 网站概述

### 1.1 网站名称
温暖小木屋

### 1.2 网站描述
一个像小木屋一样的个人展示网站，传递温暖亲切的氛围，让用户感觉像被邀请进屋喝茶一样，慢慢浏览主人的收藏、作品和热爱。这是一个爱动手、爱分享的生活家的线上空间，用项目记录成长，用兴趣点亮日常。

## 2. 网站功能

### 2.1 门廊（首页）
- 打招呼功能，显示欢迎语
- 快速导航到各个板块
- 展示用户上传的头像照片（头像.jpg）
- 手写体欢迎语展示
- 点击式导航，同一页面内切换各部分
- 右上角添加小锁样式图标，点击直达后台管理界面

### 2.2 侧边栏导航
- 固定在页面侧边的导航菜单
- 包含所有主要板块的导航链接
- 支持点击切换页面内容区域
- 保持页面滚动位置

### 2.3 客厅（关于我）
- 个人故事展示
- 时间轴形式呈现人生重要节点
- 项目/兴趣背后的故事说明
- 点击导航在同一页面切换内容

### 2.4 工作桌（项目集）
- 项目展示功能
- 每个项目配生活化封面图
- 项目详情页包含过程照片、动图、反思
- 项目难度和有趣细节标注
- 点击查看项目详情，在同一页面展示

### 2.5 收藏架（兴趣角）
- 兴趣爱好展示
- Polaroid相框样式图片展示
- 图片背面心情注释功能
- 点击查看兴趣内容在同一页面显示

### 2.6 留言簿（联系我）
- 互动表单功能
- 「写明信片」式表单设计
- 支持图片和视频文件上传
- 画板功能，用户可绘制图形并生成图片
- 提交成功动画反馈
- 显示联系邮箱：1660296253@qq.com
- 点击式交互，在同一页面完成表单提交

### 2.7 访问管理（后端功能）
- 网站访问记录追踪
- 访客IP地址、访问时间、页面路径记录
- 访问统计分析
- 邮件通知功能，当有新访问或新留言时发送通知
- 管理后台查看访问日志和邮件记录

### 2.8 后台管理系统
- 密码保护的管理后台
- 通过密码验证登录访问
- 查看网站访问记录详情
- 查看收到的邮件内容
- 管理留言和评论
- 数据统计和分析展示

## 3. 网站设计风格

### 3.1 配色方案
- 主色调：奶油白 (#FFF8F0) + 燕麦棕 (#D4B996)
- 点缀色：鼠尾草绿 (#A8C09A) 与 暮霞粉 (#F2C6C2)
- 背景色：细格纸纹理背景（极淡）\n
### 3.2 字体设计
- 标题字体：手写风「ZCOOL 快乐体」或「霞鹜文楷」
- 正文字体：清晰柔和的「思源黑体」

### 3.3 视觉细节
- 1px 手绘风格分隔线
- 按钮采用「邮票」圆角小标签设计
- Polaroid相框样式图片展示
- 温暖小细节动画效果
- 点击交互动画反馈
- 小锁图标采用金属质感设计，与整体温暖风格协调

### 3.4 整体布局
- 卡片式布局，模拟小木屋内部结构
- 温暖亲切的手工感、轻复古风格
- 逐层展开的探索式体验
- 单页面应用结构，点击导航在同一页面切换内容区域
- 侧边栏采用木纹质感，与整体风格呼应
- 后台管理界面保持与主站风格统一

这里是我用代码、镜头和一点点好奇心搭的小木屋。

它们不一定完美，却记录了我从『不会』到『会一点点』的过程。

## 5. 技术方案

### 5.1 后端服务
- 使用Netlify Functions或Vercel Functions部署Node.js后端
- 集成数据库服务（如Supabase或FaunaDB）存储访问记录
- 邮件服务集成（如SendGrid或Mailgun）发送访问通知
- API接口保护和认证机制
- 用户认证系统，支持密码验证

### 5.2 后台管理系统
- 基于React或Vue构建的管理界面
- 密码验证登录功能
- 访问日志查询和展示
- 邮件记录查看
- 数据统计图表
- 部署到Netlify或Vercel

### 5.3 静态生成
- 使用VitePress或Next.js静态导出
- 实现单页面应用架构
- 部署到Vercel平台
- Markdown格式项目日志编写

### 5.4 图片视频存储
- GitHub仓库存储 + next/image自动压缩
- 或使用Cloudinary免费版
- 支持视频文件上传和预览

### 5.5 画板功能
- 基于HTML5 Canvas的在线画板
- 支持多种画笔工具
- 画完可导出为图片格式
- 与表单集成，图片自动附加到邮件

### 5.6 评论/留言系统
- GitHub Issues + Utterances集成
- 无后端配置
- 表单提交后在同一页面显示反馈
- 支持多媒体附件

### 5.7 域名建议
- .me或.life后缀
- 便宜亲切，例如：yourname.me
