# 温暖小木屋 - 使用指南

## 网站导航

### 桌面端（屏幕宽度 ≥ 1280px）
- 左侧显示固定侧边栏
- 点击侧边栏中的导航项切换内容区域
- 当前选中的导航项会高亮显示

### 移动端（屏幕宽度 < 1280px）
- 顶部显示网站标题"温暖小木屋"
- 底部显示导航栏，包含5个导航按钮
- 点击底部导航按钮切换内容区域
- 当前选中的按钮会高亮显示

## 五大内容区域

### 1. 门廊（首页）🏡
**功能**：欢迎页面，网站的入口
**内容**：
- 个人头像展示
- 手写体欢迎语
- 快速导航按钮（可直接跳转到其他区域）
- 装饰性动画元素

**交互**：
- 点击快速导航按钮可跳转到对应区域
- 装饰元素有可爱的弹跳动画

### 2. 客厅（关于我）👤
**功能**：展示个人故事和成长历程
**内容**：
- 个人故事介绍
- 时间轴展示重要节点
- 温暖的卡片式布局

**交互**：
- 滚动浏览时间轴
- 时间轴事件有淡入动画

### 3. 工作桌（项目集）💼
**功能**：展示个人项目作品
**内容**：
- 项目卡片网格
- 项目封面图
- 难度标签（简单/中等/挑战）
- 技术标签

**交互**：
- 点击项目卡片查看详情
- 悬停时卡片有上浮效果
- 详情弹窗显示完整项目信息
- 点击弹窗外部或关闭按钮关闭详情

### 4. 收藏架（兴趣角）❤️
**功能**：展示个人兴趣爱好
**内容**：
- Polaroid相框样式的图片
- 每张照片都有标题
- 照片背面有心情注释

**交互**：
- 点击照片翻转查看背面注释
- 再次点击翻转回正面
- 悬停时照片有旋转和放大效果
- 每张照片有不同的旋转角度

### 5. 留言簿（联系我）✉️
**功能**：访客留言和联系方式
**内容**：
- 联系邮箱显示
- 明信片风格的留言表单
- 邮票装饰元素

**交互**：
- 填写姓名、邮箱、留言内容
- 点击"寄出明信片"提交表单
- 提交成功后显示动画反馈
- 3秒后自动重置表单

## 设计特色

### 视觉风格
- **配色**：奶油白、燕麦棕、鼠尾草绿、暮霞粉
- **字体**：手写风格标题 + 优雅正文字体
- **背景**：细腻的纸张纹理
- **装饰**：手绘风格分隔线、邮票样式按钮

### 动画效果
- **淡入动画**：内容切换时的平滑过渡
- **悬停效果**：卡片和按钮的微妙动画
- **翻转动画**：Polaroid相框的3D翻转
- **弹跳动画**：装饰元素的可爱动效

### 交互细节
- **邮票按钮**：虚线边框的独特按钮样式
- **温暖卡片**：悬停时的阴影和位移效果
- **手绘分隔线**：增添手工感的线条动画
- **Polaroid相框**：复古的照片展示方式

## 内容定制

### 修改个人信息
编辑以下文件可以修改网站内容：

1. **首页欢迎语**：`src/components/sections/HomeSection.tsx`
2. **关于我内容**：`src/components/sections/AboutSection.tsx`
3. **项目列表**：`src/components/sections/ProjectsSection.tsx`
4. **兴趣爱好**：`src/components/sections/InterestsSection.tsx`
5. **联系邮箱**：`src/components/sections/ContactSection.tsx`

### 更换头像
替换 `public/images/avatar.jpg` 文件即可

### 修改配色
编辑 `src/index.css` 文件中的 CSS 变量
