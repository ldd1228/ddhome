# 邮件发送功能配置说明

## 功能说明

当访客在"留言簿"页面填写并提交明信片表单后，留言内容会自动发送到您的邮箱：**1660296253@qq.com**

## 技术实现

- **后端服务**：Supabase Edge Function
- **邮件服务**：Resend（免费邮件发送服务）
- **发送方式**：异步发送，带加载状态和成功反馈

## 配置步骤

### 1. 注册 Resend 账号

1. 访问 [Resend 官网](https://resend.com)
2. 点击 "Sign Up" 注册账号（可以使用 GitHub 账号快速注册）
3. 验证邮箱地址

### 2. 获取 API Key

1. 登录 Resend 控制台
2. 进入 "API Keys" 页面
3. 点击 "Create API Key"
4. 输入名称（例如：warm-cabin-contact）
5. 复制生成的 API Key（格式：`re_xxxxxxxxxx`）

### 3. 配置 Supabase 环境变量

您需要将 Resend API Key 配置到 Supabase 项目中：

**方法一：通过秒哒平台配置**
1. 登录秒哒平台
2. 进入您的项目
3. 找到 Supabase 配置
4. 添加环境变量：
   - 名称：`RESEND_API_KEY`
   - 值：您的 Resend API Key

**方法二：通过代码配置**
已经为您预设了占位符，您只需要替换真实的 API Key：
```bash
# 当前配置的占位符
RESEND_API_KEY=re_placeholder_key_please_replace_with_real_key
```

### 4. 验证配置

配置完成后，访客提交留言时：
1. 表单会显示"正在发送..."加载状态
2. 发送成功后显示"收到啦！"动画
3. 您的邮箱会收到格式化的留言邮件

## 邮件内容格式

## 自定义发件地址（可选）

如果您想使用自己的域名作为发件地址：

1. 在 Resend 控制台添加您的域名
2. 配置 DNS 记录（Resend 会提供详细说明）
3. 验证域名
4. 修改 Edge Function 中的 `from` 字段：
   ```typescript
   from: 'Warm Cabin <noreply@yourdomain.com>'
   ```

## 故障排查

### 问题：提交后显示"发送失败"

**可能原因**：
1. Resend API Key 未配置或配置错误
2. 网络连接问题
3. Resend 服务暂时不可用

**解决方法**：
1. 检查 API Key 是否正确配置
2. 查看浏览器控制台的错误信息
3. 检查 Supabase Edge Function 日志

### 问题：没有收到邮件

**可能原因**：
1. 邮件被归类到垃圾邮件
2. 邮箱地址配置错误
3. Resend 账号未验证

**解决方法**：
1. 检查垃圾邮件文件夹
2. 确认 Edge Function 中的收件邮箱地址正确
3. 确保 Resend 账号已完成邮箱验证

### 问题：QQ 邮箱收不到邮件

**解决方法**：
1. 检查 QQ 邮箱的"反垃圾"设置
2. 将 `onboarding@resend.dev` 添加到白名单
3. 或者使用自定义域名发送邮件
